# 目录结构

```
ningxiang
├── ningxiang-api -- api接口，仅对内使用，一般用来放feign的接口，对内使用
├   └── ningxiang-api-auth -- 授权 feign接口（只要需要授权验证的微服务，就需要用到该接口）
├   └── ningxiang-api-leaf -- 分布式id feign接口（需要生成分布式唯一id的，就需要用到该接口）
├   └── ningxiang-api-rbac -- 用户角色权限 feign接口（如果一个服务，需要校验菜单权限，就需要用到该接口）
├── ningxiang-auth -- 授权服务，用户登陆生成token并返回，token的校验等就是使用该服务的
├── ningxiang-biz -- 第三方业务服务，如minio文件上传等
├── ningxiang-common -- 一些公共业务
├   └── ningxiang-common-cache -- 缓存模块
├   └── ningxiang-common-core -- 一些常用核心代码模块
├   └── ningxiang-common-database -- 数据库模块
├   └── ningxiang-common-database -- 验证授权等安全模块
├── ningxiang-gateway -- 网关服务
├── ningxiang-leaf -- 分布式id服务（使用美团的leaf创建分布式id）
├── ningxiang-multishop -- 商家服务
├── ningxiang-order -- 订单服务
├── ningxiang-payment -- 支付服务
├── ningxiang-platform -- 平台服务
├── ningxiang-product -- 商品服务
├── ningxiang-rbac -- 菜单服务
├── ningxiang-search -- 搜索服务（使用elasticsearch实现）
├── ningxiang-user -- 用户服务
```
